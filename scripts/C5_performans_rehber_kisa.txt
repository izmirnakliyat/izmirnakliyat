C5 — Performans: CDN, görseller, CSS (kısa rehber)
====================================================

1) Cloudflare (veya benzeri CDN) — ön koşul: DNS bölgesi
   - A/CNAME "proxied" (turuncu bulut) açık olsun; böylece önbellek + gzip/Brotli faydalanılır.
   - Page Rules / Cache Rules: statik .css, .js, .woff2 için uzun süre cache (HTML kısa TTL veya by-pass, içerik güncellemesine göre).
   - "Always Use HTTPS" ve SSL "Full" (strict) sertifika uyuşmazlığı yoksa.

2) Görüller: WebP / modern format
   - Yükleme: mümkünse (ör. 1200px üstü hero) 80–85 kalite WebP; fallback JPG sunumu için <picture> veya sunucu varyant.
   - Mevcut büyük JPG/PNG: toplu dönüştürme = offline araç (cwebp, Squoosh) veya barındırıcı "image optimization" eklentisi.
   - `uploads/` görselleri: sayfa ağırlığını düşürmek için LCP hedefinde tek büyük görsel; lazy loading zaten <img> için kullanıldığı yerde korunur.

3) Kritik CSS
   - İlk ekran (above the fold) için 10–20 satır "inline" kritik stil, geri kalan `main.css` zaten defer/son yükleme ile uyumluysa bırakılabilir.
   - Tam "critical path extract" ağır: önce sayfa hız testi (PageSpeed, WebPageTest) ile darboğazı görün, sonra sadece LCP etiketine odaklanın.

4) Ölçüm
   - Canlı: Chrome Lighthouse; Core Web Vitals (GSC) — deploy sonrası 28 gün veri toplanır.
   - Yerel: `network` throttling "Slow 4G" ile smoke test.

Bu dosya operasyonel nottur; sitede yayımlanmaz.
